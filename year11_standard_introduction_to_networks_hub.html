Key terms
Degree (networks)
Number of edge ends incident to a vertex; a loop counts twice.
Directed network
A network whose edges have directions indicated by arrows.
Edge (networks)
A connection between vertices.
Network
A collection of vertices and edges representing connections.
Vertex (networks)
A point or node in a network.
Weighted edges
Edges assigned numerical values such as distance, cost or time.

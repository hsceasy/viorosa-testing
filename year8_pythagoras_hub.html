Lesson 05

Finding a shorter side

In a right triangle, a² + b² = c², where c is the hypotenuse. Use the positive square root for a length.

Worked example

Find the missing leg when hypotenuse = 13 cm and other leg = 12 cm.

x² + 12² = 13²
x² + 144 = 169
x² = 169 − 144
x² = 25
x = √25
x = 5 cm

Now you try

Find the missing leg when hypotenuse = 41 cm and other leg = 40 cm.

Show worked solution

x² + 40² = 41²
x² + 1600 = 1681
x² = 1681 − 1600
x² = 81
x = √81
x = 9 cm

Lesson 06

Checking right triangles

In a right triangle, a² + b² = c², where c is the hypotenuse. Use the positive square root for a length.

Worked example

Is a triangle with sides 8, 15, 17 cm right-angled?

8² + 15² = 64 + 225
= 289
17² = 289
The values agree, so yes.

Now you try

Is a triangle with sides 20, 21, 29 cm right-angled?

Show worked solution

= 841

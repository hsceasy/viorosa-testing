Lesson 01

Slope-intercept form

In y = mx + b, m is gradient and b is the y-intercept.

Worked example

Identify m and b for y = 2x + 1.

m = 2
b = 1, so the intercept is (0,1).

Now you try

Identify the gradient of y = −3x + 4.

Show worked solution

m = −3

Lesson 02

Writing equations

Substitute the given gradient and y-intercept into y = mx + b.

Worked example

Write the equation with gradient −2 and intercept 3.

m = −2, b = 3
y = −2x + 3

Now you try

Write the equation with gradient 3 and intercept −1.

Show worked solution

y = 3x − 1

Lesson 03

Graphing positive gradients

Start at the y-intercept and use rise over run.

Worked example

Graph y = 2x + 1.

Plot (0,1)
Rise 2 and run 1 to (1,3)
Draw the straight line.

Now you try

Find y at x = 2.

Show worked solution

2 × 2 + 1 = 5

Lesson 04

Graphing negative gradients

A negative gradient falls as x increases.

Worked example

Graph y = −x + 3.

Plot (0,3)
Move right 1 and down 1 to (1,2)
Draw the line.

Now you try

Find y when x = 4.

Show worked solution

−4 + 3 = −1

Lesson 05

Fractional gradients

Use the numerator as rise and denominator as run, including the sign.

Worked example

Graph y = 0.5x − 1.

Start at (0,−1)
m = 12
Move right 2 and up 1 to (2,0).

Now you try

Find y at x = 6.

Show worked solution

0.5 × 6 − 1 = 2

Lesson 06

Reading a graph

Read the intercept and calculate gradient from two points.

Worked example

A line passes through (0,2) and (2,6).

m = 6 − 22 − 0 = 2
b = 2
y = 2x + 2

Now you try

Find the equation through (0,1) and (2,7).

Show worked solution

m = 7 − 12 = 3
y = 3x + 1

Lesson 07

Changing gradient

Larger absolute gradient means a steeper line; the sign determines direction.

Worked example

Compare y = x + 1 and y = 3x + 1.

Both cross (0,1).
The second rises 3 units per unit of run.
It is steeper.

Now you try

Which is steeper: y = −4x or y = 2x?

Show worked solution

Absolute gradients: 4 > 2, so y = −4x.

Lesson 08

Real-life linear models

Gradient is the rate of change and intercept is the starting value.

Worked example

A taxi costs $4 plus $2 per kilometre.

C = 2d + 4
For 5 km: C = 10 + 4 = $14

Now you try

Find the cost for 8 km.

Show worked solution

2 × 8 + 4 = $20

Lesson 09

Parallel lines

Distinct nonvertical parallel lines have equal gradients.

Worked example

Find a parallel line to y = 2x + 1 through (0,−3).

m = 2
b = −3
y = 2x − 3

Now you try

Find the gradient of a line parallel to y = −3x + 2.

Show worked solution

m = −3

Lesson 10

Perpendicular gradients

Nonvertical perpendicular lines have gradients whose product is −1.

Worked example

Find the gradient perpendicular to m = 2.

2m₂ = −1
m₂ = −12

Now you try

Find the gradient perpendicular to −4.

Show worked solution

m₂ = 14

Lesson 11

Parallel line through a point

Use the shared gradient and substitute the point to find b.

Worked example

Find the parallel to y = 2x + 1 through (3,4).

4 = 2 × 3 + b
b = −2
y = 2x − 2

Now you try

Find the parallel to y = 3x through (2,7).

Show worked solution

7 = 6 + b
b = 1
y = 3x + 1

Lesson 12

Perpendicular line through a point

Use the negative reciprocal gradient, then substitute the point.

Worked example

Find the perpendicular to y = 2x + 1 through (2,3).

m = −12
3 = −0.5 × 2 + b
b = 4
y = −0.5x + 4

Now you try

Find the perpendicular to y = −x through (2,5).

Show worked solution

m = 1
5 = 2 + b
b = 3
y = x + 3

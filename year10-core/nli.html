Lesson 01

Parabolas

A quadratic graph has a squared variable and a parabolic shape.

Worked example

Describe y = x².

Vertex (0,0)
Opens upwards
Axis of symmetry x = 0.

Now you try

Describe y = −x².

Show worked solution

Opens downwards.

Lesson 02

Quadratic tables

Substitute each x value into the equation.

Worked example

Find y = 2x² at x = −2, −1, 0, 1, 2.

2 × 4 = 8
2 × 1 = 2
0
2
8

Now you try

Find y = 2x² at x = 3.

Show worked solution

2 × 9 = 18

Lesson 03

Concavity and width

The sign of a in y = ax² determines concavity; larger absolute a makes the parabola narrower.

Worked example

Compare y = x² and y = 3x².

Both open upwards.
At x = 1 the heights are 1 and 3.
The second is narrower.

Now you try

Which is narrower: y = x² or y = 4x²?

Show worked solution

4 > 1, so y = 4x².

Lesson 04

Vertical translations

Adding c to y = ax² moves the graph vertically by c.

Worked example

Describe y = x² − 3.

Shift down 3 units.
Vertex (0,−3).

Now you try

Find the vertex of y = x² + 4.

Show worked solution

(0,4)

Lesson 05

Identifying quadratic equations

Use the vertex and another point to identify a in y = ax² + c.

Worked example

Vertex (0,2), point (2,10).

c = 2
10 = 4a + 2
a = 2
y = 2x² + 2

Now you try

Find a if y = ax² + 1 passes through (2,13).

Show worked solution

13 = 4a + 1
a = 3

Lesson 06

Exponential growth

In y = bˣ with b > 1, equal steps in x multiply y by b.

Worked example

Plot y = 2ˣ for x = 0,1,2,3.

1, 2, 4, 8
The y-intercept is (0,1).

Now you try

Find 3³.

Show worked solution

3 × 3 × 3 = 27

Lesson 07

Exponential decay

For 0 < b < 1, y = bˣ decreases as x increases.

Worked example

Evaluate y = (0.5)ˣ at x = 0,1,2,3.

1, 0.5, 0.25, 0.125

Now you try

Find (0.5)⁴.

Show worked solution

0.125 × 0.5 = 0.0625

Lesson 08

Asymptotes and intercepts

An asymptote is a line a curve approaches. For y = bˣ the horizontal asymptote is y = 0.

Worked example

Describe y = 3ˣ.

Crosses (0,1)
Always positive
Approaches y = 0 as x decreases.

Now you try

State the y-intercept of y = 5ˣ.

Show worked solution

5⁰ = 1, so (0,1).

Lesson 09

Matching graphs

Linear graphs have constant differences; quadratic graphs have constant second differences; exponential graphs have constant ratios.

Worked example

Compare y = 2x, y = x² and y = 2ˣ.

At x = 1,2,3: linear 2,4,6; quadratic 1,4,9; exponential 2,4,8.

Now you try

Identify the type of y = 4ˣ.

Show worked solution

Variable is in the exponent.

Lesson 10

Graphical simultaneous equations

Graph both equations using a graphing application and read intersections.

Worked example

Solve y = x² and y = x + 2.

Intersections (−1,1) and (2,4)
Check: 1 = −1 + 2 and 4 = 2 + 2.

Now you try

Solve y = x² and y = 9 for x.

Show worked solution

x = −3 or 3

Lesson 11

Number of solutions

The number of intersections gives the number of simultaneous solutions.

Worked example

Compare y = x² with y = −1, y = 0 and y = 4.

No intersection; one intersection (0,0); two intersections (−2,4),(2,4).

Now you try

How many intersections have y = x² and y = −4?

Show worked solution

None because x² ≥ 0.

Lesson 12

Modelling and checking

Choose a model based on the pattern and check graphical solutions by substitution.

Worked example

A population doubles each hour from 1 unit. Compare y = 2ˣ with y = 4.

Intersection (2,4)
2² = 4, so 2 hours.

Now you try

When does y = 2ˣ reach 8?

Show worked solution

2³ = 8, so x = 3.

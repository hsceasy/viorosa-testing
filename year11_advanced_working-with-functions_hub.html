Course Notes

Key terms
Absolute value
Distance from zero.
Asymptote
A line a graph approaches in a limiting direction.
Axis of symmetry
A line about which a graph is mirror symmetric.
Composite function
A function formed by applying one function to the output of another.
Conjugate
For a binomial surd, the expression with the sign between terms reversed.
Discriminant
The quantity b² − 4ac for a quadratic.
Domain
The set of allowed inputs.
Range
The set of attained outputs.
Function
A relation assigning exactly one output to each input.
Relation
An association between elements of sets.
Gradient
Rate of change of vertical coordinate with horizontal coordinate.
Intercept
A point where a graph meets an axis.
Vertex
The turning point of a parabola.
Zero
An input at which a function equals zero.
Root
A solution of an equation.
Even function
A function symmetric about the vertical axis.
Odd function
A function symmetric under a half-turn about the origin.
Discontinuity
A point where a function is not continuous.
Direct variation
A relationship with constant ratio y/x.
Inverse variation
A relationship with constant product xy.
Surd
An irrational root expressed exactly.
Piecewise-defined function
A function specified by different rules on different input sets.
Break-even point
Where revenue equals cost.
Algebraic techniques

Use index laws for nonzero bases; fractional powers represent roots. Expand using distributivity and factorise by common factors, difference of squares or grouping. For algebraic fractions, factor before cancelling and retain original denominator restrictions. Simplify surds by extracting square factors; rationalise using a conjugate. Solve quadratics by factoring, completing the square or the quadratic formula. The discriminant determines whether real roots are distinct, repeated or absent; for rational coefficients, rational roots require a rational square root of the discriminant.

Worked example\[\frac{x^2-9}{x-3}=x+3\quad(x\ne3)\]\[\frac{1}{2+\sqrt3}=2-\sqrt3\]\[x^2-6x+5=(x-3)^2-4=0\Rightarrow x=1,5\]
Introduction to functions and relations

A relation associates elements of sets. A function assigns exactly one output to each input. Represent relations using ordered pairs, tables, equations or graphs. The vertical line test checks uniqueness. The domain is the allowed inputs and the range is the attained outputs. A zero is an input giving output zero. The independent variable is the input; the dependent variable is the output.

Worked example\[f(x)=x^2-4,\quad f(a+1)=a^2+2a-3\]\[f(x)=0\Rightarrow x=\pm2\]\[\text{Domain }\mathbb R,\quad\text{range }[-4,\infty)\]
Linear functions

Use gradient–intercept, general and point–gradient forms. Find gradient from two points. Parallel nonvertical lines have equal gradients; perpendicular nonvertical lines have gradients whose product is −1. Horizontal and vertical lines are perpendicular. Find intercepts by setting the other coordinate to zero. Reverse an inequality when multiplying or dividing by a negative number.

Worked example\[m=\frac{7-1}{4-2}=3\]\[y-1=3(x-2)\Rightarrow y=3x-5\Rightarrow 3x-y-5=0\]\[-2x+4>10\Rightarrow x<-3\]
Quadratic and cubic functions

For a quadratic, use the discriminant for intercepts and complete the square for the vertex. The axis is x = −b/(2a). Match coefficients when two polynomial expressions are identical. Solve intersections by equating functions; use roots and the sign of the leading coefficient for inequalities. Cubics of the form ax³ and a(x−h)³+k have an inflection at the origin or (h,k).

Worked example\[y=x^2-4x+3=(x-2)^2-1\]\[y=0\Rightarrow x=1,3;\quad x^2-4x+3<0\Rightarrow 1
Reciprocal functions

Reciprocal functions y=k/x, with nonzero k, have asymptotes x=0 and y=0. The sign of k determines the occupied quadrants. As the magnitude of x increases, y approaches zero; near zero the magnitude of y increases without bound.

Worked example\[y=\frac{6}{x}\]\[x\to0^+\Rightarrow y\to+\infty\]\[x\to-\infty\Rightarrow y\to0^-\]
Constructing and using functions

Choose variables and realistic domains before constructing models. Linear equations model constant rates; simultaneous equations locate intersections and break-even points. Inequalities model constraints. Quadratics can model maximum or minimum quantities. Interpret every solution in context.

Worked example\[C=120+4n,\quad R=10n\]\[C=R\Rightarrow 120=6n\Rightarrow n=20\]\[P=6n-120>0\Rightarrow n\ge21\quad(n\text{ integer})\]
Direct and inverse variation

Direct variation means y=kx; inverse variation means y=k/x. Determine k from a known pair and substitute to predict another value. Check units and realistic domains.

Worked example\[y=18\text{ when }x=3\Rightarrow k=6\text{ (direct)}\]\[y=18\text{ when }x=3\Rightarrow k=54\text{ (inverse)}\]\[x=9\Rightarrow y=54\text{ (direct) or }6\text{ (inverse)}\]
Circles and semicircles

Pythagoras gives the equation of a circle centred at the origin. Isolate y to obtain upper and lower semicircles, or isolate x for left and right semicircles. A whole circle fails the vertical line test.

Worked example\[x^2+y^2=25\]\[y=\pm\sqrt{25-x^2}\]\[x=\pm\sqrt{25-y^2}\]
Properties of functions, relations and graphs

Express domains and ranges using intervals or inequalities. Even functions satisfy f(−x)=f(x) and odd functions satisfy f(−x)=−f(x), on symmetric domains. Composition applies the inner function first; restrict inputs so both stages are defined.

Worked example\[f(x)=x^2,\ g(x)=x+3\]\[(f\circ g)(x)=(x+3)^2\]\[(g\circ f)(x)=x^2+3\]
Piecewise-defined functions

A piecewise function uses different rules on different parts of its domain. Draw each rule only on its stated interval. Use open circles for excluded endpoints and closed circles for included endpoints. A jump or hole is a discontinuity. Check symmetry and range across all pieces.

Worked example\[f(x)=\begin{cases}x+2&x<0\\x^2&x\ge0\end{cases}\]\[f(-1)=1,\quad f(0)=0\]\[\text{Domain }\mathbb R,\quad\text{range }\mathbb R\]
Absolute value functions

Absolute value measures distance from zero. It equals x for nonnegative x and −x otherwise. Its graph is even. To graph |f(x)|, reflect negative portions of f above the horizontal axis. Solve |f(x)|=c by considering f(x)=c or f(x)=−c for nonnegative c.

Worked example\[|x|=\sqrt{x^2}\]\[|2x-3|=5\Rightarrow 2x-3=\pm5\]\[x=4\text{ or }x=-1\]

Key terms
Absolute value
Distance from zero.
Asymptote
A line a graph approaches in a limiting direction.
Axis of symmetry
A line about which a graph is mirror symmetric.
Composite function
A function formed by applying one function to the output of another.
Conjugate
For a binomial surd, the expression with the sign between terms reversed.
Discriminant
The quantity b² − 4ac for a quadratic.
Domain
The set of allowed inputs.
Range
The set of attained outputs.
Function
A relation assigning exactly one output to each input.
Relation
An association between elements of sets.
Gradient
Rate of change of vertical coordinate with horizontal coordinate.
Intercept
A point where a graph meets an axis.
Vertex
The turning point of a parabola.
Zero
An input at which a function equals zero.
Root
A solution of an equation.
Even function
A function symmetric about the vertical axis.
Odd function
A function symmetric under a half-turn about the origin.
Discontinuity
A point where a function is not continuous.
Direct variation
A relationship with constant ratio y/x.
Inverse variation
A relationship with constant product xy.
Surd
An irrational root expressed exactly.
Piecewise-defined function
A function specified by different rules on different input sets.
Break-even point
Where revenue equals cost.

Example 1 · Foundation

Simplify \(x^3x^{-5}\), where \(x\ne0\).

What are we finding?

Write as a single power with a positive index.

What do we know?

Both powers have base x.

Which method should we use?

When multiplying powers with the same base, add the indices.

Step-by-step solution

Step 1. Keep the base x and add the indices: \(3+(-5)=-2\).

Step 2. Write \(x^{-2}\). A negative index means take the reciprocal, not make the number negative.

Final answer: \(\frac{1}{x^2}\)

Common mistake: Do not multiply the indices.

Example 2 · Developing

Rationalise \(\frac{3}{2+\sqrt3}\).

What are we finding?

Remove the surd from the denominator.

What do we know?

The conjugate of \(2+\sqrt3\) is \(2-\sqrt3\).

Which method should we use?

Multiply numerator and denominator by the conjugate so the middle terms cancel.

Step-by-step solution

Step 1. Multiply by \(\frac{2-\sqrt3}{2-\sqrt3}\), which equals 1.

Step 2. Expand the denominator: \((2+\sqrt3)(2-\sqrt3)=4-3=1\).

Step 3. Expand the numerator: \(3(2-\sqrt3)=6-3\sqrt3\).

Final answer: \(6-3\sqrt3\)

Common mistake: Multiply both numerator and denominator, not just the denominator.

Example 3 · Challenge

Find k so \(x^2-6x+k=0\) has equal roots.

What are we finding?

Find the constant that makes the two roots coincide.

What do we know?

\(a=1,b=-6,c=k\).

Which method should we use?

Equal roots occur when the discriminant is zero.

Step-by-step solution

Step 1. Use \(\Delta=b^2-4ac\).

Step 2. Substitute: \(\Delta=36-4k\).

Step 3. Set \(36-4k=0\), so \(4k=36\).

Step 4. Divide by 4; the repeated root is \(x=3\).

Final answer: \(k=9\)

Common mistake: Equal roots means zero discriminant, not a negative discriminant.

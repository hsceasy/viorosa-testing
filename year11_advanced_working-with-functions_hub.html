Key terms
Absolute value
Distance from zero.
Asymptote
A line a graph approaches in a limiting direction.
Axis of symmetry
A line about which a graph is mirror symmetric.
Composite function
A function formed by applying one function to the output of another.
Conjugate
For a binomial surd, the expression with the sign between terms reversed.
Discriminant
The quantity b² − 4ac for a quadratic.
Domain
The set of allowed inputs.
Range
The set of attained outputs.
Function
A relation assigning exactly one output to each input.
Relation
An association between elements of sets.
Gradient
Rate of change of vertical coordinate with horizontal coordinate.
Intercept
A point where a graph meets an axis.
Vertex
The turning point of a parabola.
Zero
An input at which a function equals zero.
Root
A solution of an equation.
Even function
A function symmetric about the vertical axis.
Odd function
A function symmetric under a half-turn about the origin.
Discontinuity
A point where a function is not continuous.
Direct variation
A relationship with constant ratio y/x.
Inverse variation
A relationship with constant product xy.
Surd
An irrational root expressed exactly.
Piecewise-defined function
A function specified by different rules on different input sets.
Break-even point
Where revenue equals cost.

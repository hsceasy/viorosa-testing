Key terms
Data
Collected observations or measurements.
Dataset
A collection of related data.
Population
Entire group of interest.
Sample
Subset of a population.
Variable
Characteristic recorded for each observation.
Categorical data
Values representing groups.
Categorical variable
Variable with category responses.
Numerical data
Counts or measurements.
Numerical variable
Variable with quantitative responses.
Discrete variable
Countable numerical values.
Continuous variable
Measurements on a continuum.
Nominal variable
Unordered categories.
Ordinal variable
Ordered categories.

Lesson 01

Collecting like terms

Only combine terms with identical variable factors.

Worked example

Simplify 5x + 3y − 2x.

= (5 − 2)x + 3y
= 3x + 3y

Now you try

Simplify 7a − 2b − 4a.

Show worked solution

= (7 − 4)a − 2b
= 3a − 2b

Lesson 02

Simplifying fractions

Divide numerator and numerical denominator by a common factor.

Worked example

Simplify 12x18.

= 6 × 2x6 × 3
= 2x3

Now you try

Simplify 15a25.

Show worked solution

= 5 × 3a5 × 5
= 3a5

Lesson 03

Adding fractions

Find a common denominator before adding numerators.

Worked example

Simplify x3 + 2x5.

= 5x15 + 6x15
= 5x + 6x15
= 11x15

Now you try

Simplify a4 + a6.

Show worked solution

= 3a12 + 2a12
= 5a12

Lesson 04

Subtracting fractions

Subtract the entire second numerator.

Worked example

Simplify 3x4 − x + 26.

= 9x12 − 2(x + 2)12
= 9x − 2x − 412
= 7x − 412

Now you try

Simplify 2a3 − a + 12.

Show worked solution

= 4a6 − 3(a + 1)6
= 4a − 3a − 36
= a − 36

Lesson 05

Multiplying fractions

Multiply numerators and denominators, then simplify.

Worked example

Simplify 3x4 × 2y9.

= 6xy36
= xy6

Now you try

Simplify 4a5 × 3b8.

Show worked solution

= 12ab40
= 3ab10

Lesson 06

Dividing fractions

Multiply by the reciprocal of the nonzero divisor.

Worked example

Simplify 5x6 ÷ 23.

= 5x6 × 32
= 15x12
= 5x4

Now you try

Simplify 3a8 ÷ 34.

Show worked solution

= 3a8 × 43
= 12a24
= a2

Lesson 07

Expanding brackets

Multiply every term inside brackets, including signs.

Worked example

Expand −3(2x − 5).

= (−3)(2x) + (−3)(−5)
= −6x + 15

Now you try

Expand −4(a − 3).

Show worked solution

= (−4)a + (−4)(−3)
= −4a + 12

Lesson 08

Expanding and simplifying

Expand each bracket, then collect like terms.

Worked example

Simplify 2(x + 3) − 3(x − 4).

= 2x + 6 − 3x + 12
= (2 − 3)x + (6 + 12)
= −x + 18

Now you try

Simplify 3(a + 2) − 2(a − 5).

Show worked solution

= 3a + 6 − 2a + 10
= (3 − 2)a + (6 + 10)
= a + 16

Lesson 09

Binomial products

Multiply each term of one bracket by each term of the other.

Worked example

Expand (x + 2)(x + 3).

= x(x + 3) + 2(x + 3)
= x² + 3x + 2x + 6
= x² + 5x + 6

Now you try

Expand (a + 4)(a + 2).

Show worked solution

= a(a + 2) + 4(a + 2)
= a² + 2a + 4a + 8
= a² + 6a + 8

Lesson 10

Signed binomial products

Keep the sign attached to each term.

Worked example

Expand (2x − 3)(x + 4).

= 2x(x + 4) − 3(x + 4)
= 2x² + 8x − 3x − 12
= 2x² + 5x − 12

Now you try

Expand (a − 2)(a + 5).

Show worked solution

= a(a + 5) − 2(a + 5)
= a² + 5a − 2a − 10
= a² + 3a − 10

Lesson 11

Mixed operations

Use common denominators and distribute before collecting terms.

Worked example

Simplify 2(x + 3)3 + x6.

= 4(x + 3)6 + x6
= 4x + 12 + x6
= 5x + 126

Now you try

Simplify 3(a − 2)4 + a2.

Show worked solution

= 3a − 64 + 2a4
= 5a − 64

Lesson 12

Error analysis

Check expansions by substitution; one matching value alone does not prove identity.

Worked example

A student writes (x + 3)² = x² + 9. Correct it.

(x + 3)(x + 3)
= x² + 3x + 3x + 9
= x² + 6x + 9

Now you try

Expand (a − 4)².

Show worked solution

(a − 4)(a − 4)
= a² − 4a − 4a + 16
= a² − 8a + 16

Backward scanning

Critical Path Analysis course notes

Key concepts

Begin at the project completion time. At each event take the minimum of outgoing latest starts. The latest start of an arrow is the latest time of its head event minus its duration.

LST = LFT − duration; LFT = minimum successor LST

Worked example

The fair must finish by day 13. Calculate the latest start of every activity.

Worked solution
  1. E: 13−3=10; F: 13−2=11.
  2. C: 10−6=4; D: 11−4=7.
  3. A: 4−4=0; B: 7−3=4.
  4. The starting event latest time is min(0,4)=0.

Now you try

A project has A (3 days) and B (5 days), followed by C (2 days) after both. Find latest starts if completion is day 7.

Show answer
  1. C: 7−2=5.
  2. A: 5−3=2; B: 5−5=0.
  3. Latest starts are 2, 0 and 5 days.

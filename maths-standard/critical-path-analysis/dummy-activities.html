Dummy activities

Critical Path Analysis course notes

Key concepts

A dummy is a dashed directed arrow of zero duration, used to represent a dependency without adding work.

Dummy duration = 0

Worked example

A renovation has A (4 days) and B (3 days) starting together. C (6 days) requires A only; D (4 days) requires both A and B. Draw the dependency using a dummy and find the finish time.

Worked solution
  1. Draw A from 1 to 2 and B from 1 to 3.
  2. Draw a zero-duration dummy from 2 to 3, so D waits for both.
  3. Draw C from 2 to 4 and D from 3 to 4.
  4. Event 3 occurs at max(4,3)=4; C finishes at 10, D at 8.
  5. Project finishes at day 10.

Now you try

A shop has A (2 h), B (5 h), C (3 h) after A only, D (4 h) after both. Find earliest finish using a dummy.

Show answer
  1. Use dummy from end of A to end of B.
  2. C finishes at 2+3=5 h.
  3. D finishes at max(2,5)+4=9 h.
  4. Project finishes at 9 h.

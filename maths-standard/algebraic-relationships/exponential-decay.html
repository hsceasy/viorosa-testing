Exponential decay graphs

Algebraic Relationships course notes

Key concept

Exponential decay multiplies a positive starting value by a factor between zero and one. The graph decreases and approaches zero.

y = Abˣ, A > 0, 0 < b < 1

Worked example 1

Describe y = (½)ˣ.

The y-intercept is (0, 1). There is no x-intercept. The horizontal asymptote is y = 0 as x increases.

Worked example 2

A machine worth $8,000 loses 20% of its value each year. Find its value after 2 years.

$8,000 × 0.8² = $5,120.

Common mistake

Subtract the percentage from 100% to find the decay factor.

Constructing a decay model

A filter removes 25% of a substance each hour. Starting at 160 mg, M = 160 × 0.75ᵗ. The ordered pairs (0,160), (1,120), (2,90), (3,67.5) give the graph. The vertical intercept represents initial mass.

Enter y=160*0.75^x in a graphing application. The model assumes the same removal proportion each hour; it may fail if the filter wears out. Restrict time to nonnegative values.

Now you try: 240 mg decreases by 10% for 2 hours.

240 × 0.9² = 194.4 mg.

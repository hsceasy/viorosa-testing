How to find x-intercepts and y-intercepts

Algebraic Relationships course notes

Key concept

An x-intercept is where a graph meets the x-axis. A y-intercept is where it meets the y-axis.

x-intercept: set y = 0.   y-intercept: set x = 0.

Worked example 1

Find both intercepts of y = 2x − 4.

Set y = 0: 2x − 4 = 0, so x = 2. Set x = 0: y = −4. Intercepts: (2, 0) and (0, −4).

Worked example 2

Find the intercepts of y = −x + 3.

(3, 0) and (0, 3).

Common mistake

Do not swap the coordinates.

Foundations review

Coordinates are (x,y): move horizontally first. For y = 2x−1, substituting x = −1, 0, 1 gives y = −3, −1, 1. Gradient is rise divided by run. To solve 4(x−2)=20, divide by 4 then add 2 to obtain x=7. Enter y=2x−1 in a graphing application and check the points.

Interpreting algebraic models

Algebraic Relationships course notes

Key concept

Read the axes, units, domain and key features before interpreting a mathematical model.

Rate of change = change in outputchange in input

Worked example 1

A taxi fare is C = 4 + 2.5d, where d is distance in kilometres. Interpret the intercept and gradient.

The initial fare is $4; each kilometre adds $2.50. The practical domain is d ≥ 0.

Worked example 2

Find the fare for 8 km.

$4 + $2.50 × 8 = $24.

Common mistake

Do not extrapolate beyond a model’s reasonable domain.

Choose a model and explain limitations

Fixed charge plus constant unit cost suggests a linear model; repeated percentage growth suggests an exponential model; a symmetric rise and fall suggests a quadratic model; fixed work shared among workers suggests a reciprocal model. State the input units, output units and valid domain. A graph is not evidence that a model remains valid outside observed data.

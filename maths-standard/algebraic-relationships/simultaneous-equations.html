Solving simultaneous equations

Algebraic Relationships course notes

Key concept

The solution satisfies both equations. On a graph it is the intersection of the two lines.

Substitution: replace one variable with an equivalent expression.

Worked example 1

Solve y = 2x + 1 and y = −x + 7.

Equate: 2x + 1 = −x + 7. Then 3x = 6, x = 2. Substitute: y = 5.

Worked example 2

Solve x + y = 9 and x − y = 3 by elimination.

Add the equations: 2x = 12, so x = 6 and y = 3.

Common mistake

Give both coordinates and check both equations.

Break-even analysis

A stall pays $240 in fixed costs and $6 per item. Each item sells for $14. Let n be items sold. Cost C = 240 + 6n; revenue R = 14n. At break-even C = R, so 8n = 240 and n = 30. Both values are $420. At 40 items profit = 560 − 480 = $80; at 20 items loss = 360 − 280 = $80.

Graph both equations by entering them into a graphing application using x for n; use the intersection tool. By hand, plot (0,240), (30,420) for cost and (0,0), (30,420) for revenue.

Practical simultaneous equations

40 tickets sold for $400. Adult tickets cost $12 and child tickets $8. Let a and c be counts. a+c=40 and 12a+8c=400. Multiply the first by 8 and subtract: 4a=80, so a=20 and c=20. Check both totals.

Now you try: fixed cost $180, unit cost $4, selling price $10. Break-even?

180 ÷ (10−4) = 30 items.

Understanding bivariate data

Bivariate Data Analysis course notes

Key concepts

Univariate data measures one variable; bivariate data records two paired measurements on each observational unit.

One pair = (x, y)

Worked example

A shop records advertising and orders for eight weeks. Is this univariate or bivariate?
x12345678
y1217152325282734
Worked solution
  1. Each week has two measurements.
  2. The observations are paired by week.
  3. Bivariate data is needed to investigate association.

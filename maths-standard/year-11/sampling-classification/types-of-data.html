Numerical and categorical data

Learn the concept

Numerical variables measure quantities: discrete counts or continuous measurements. Categorical variables describe groups: nominal (unordered) or ordinal (ordered).

NumericalCategorical
Discrete: number of booksNominal: genre
Continuous: massOrdinal: condition rating

Worked example

Number of siblings is discrete; height is continuous even when rounded; suburb is nominal; satisfaction is ordinal. A postcode is a label, not a quantity.

Now you try

Classify rainfall, number of rainy days, transport type and service rating.

Show worked answer

Continuous, discrete, nominal and ordinal respectively.

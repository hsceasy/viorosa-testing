Box plots and parallel box plots

Learn the concept

Draw a number line, a box from Q1 to Q3, median line and whiskers to minimum and maximum for a five-number-summary plot. Modified box plots instead mark outliers separately. Use a common scale to compare centre, spread and possible skew.

Worked example

A: 2, 5, 8, 11, 14; B: 4, 7, 9, 10, 18 (five-number summaries). B has higher median, smaller IQR (3 vs 6), but larger range (14 vs 12). Its long upper whisker suggests right skew.

Expand the histogram to 2, 4, 4, 6, 6, 6, 8, 8, 10. The five-number summary is 2, 4, 6, 8, 10.

Now you try

Which has greater middle-half spread?

Show worked answer

A: IQR 6 compared with B: 3.

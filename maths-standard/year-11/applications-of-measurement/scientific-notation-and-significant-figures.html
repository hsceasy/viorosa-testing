Scientific notation and significant figures

Key idea

Scientific notation

a × 10ⁿ, where 1 ≤ a < 10

For a large number move the decimal left until one nonzero digit remains before it. Count moves: the exponent is positive. For a small positive number move right; the exponent is negative. Significant figures start at the first nonzero digit; zeros between significant digits count. Round using the next digit.

Large number

Write 583 720 to three significant figures in scientific notation.

583720 → 58372 → 5837.2 → 583.72 → 58.372 → 5.8372 (five places left)

583720 = 5.8372 × 10⁵

Fourth significant digit is 7, so round up.

≈ 5.84 × 10⁵

Small number

Write 0.00047286 to two significant figures in scientific notation.

0.00047286 → 0.0047286 → 0.047286 → 0.47286 → 4.7286 (four places right)

0.00047286 = 4.7286 × 10⁻⁴

Third significant digit is 2, so round down.

≈ 4.7 × 10⁻⁴

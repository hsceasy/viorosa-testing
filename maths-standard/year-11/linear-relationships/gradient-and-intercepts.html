Gradient and intercepts

Key idea

Gradient tells us how much y changes when x increases by one. The y-intercept is where the line crosses the vertical axis (x = 0). The x-intercept is where y = 0.

Gradient

m = riserun = y₂ − y₁x₂ − x₁

Positive gradients rise to the right; negative gradients fall. A horizontal line has gradient zero.

Equation of a line

y = mx + c

m is gradient; c is the y-intercept.

Method 1 — rise over run

Find the gradient and y-intercept.

Solution

rise = 8 − 4

rise = 4

run = 3 − 1

run = 2

m = 42

m = 2

c = 2 (read where x = 0)

y = 2x + 2

Gradient 2; y-intercept (0, 2).

Method 2 — intercept and a point

The line crosses the y-axis at 3 and passes through (2, 9). Find m.

Solution

y = mx + c

9 = 2m + 3

9 − 3 = 2m + 3 − 3

6 = 2m

62 = 2m2

3 = m

y = 3x + 3

Gradient 3; y-intercept (0, 3).

Method 3 — use both intercepts

Read the intercepts and calculate the gradient.

Solution

x-intercept = (4, 0)

y-intercept = (0, 8)

m = 0 − 84 − 0

m = −84

m = −2

y = −2x + 8

Gradient −2; y-intercept (0, 8).

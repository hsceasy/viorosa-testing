Paths, trees and spanning trees

A path does not repeat vertices. A tree is connected and contains no cycles. A spanning tree includes every original vertex, with exactly n − 1 edges.

The highlighted A–B–C path does not include D, so it is not a spanning tree of this network.

AB, BC and CD form a spanning tree: all four vertices are connected and there is no cycle.

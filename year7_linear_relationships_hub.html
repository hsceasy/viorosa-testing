MA4-LIN-C-01 · Learn, practise and mark each lesson complete to grow your blue forget-me-not.

Key terms
Cartesian plane
A plane with perpendicular x- and y-axes.
gradient
Change in y divided by change in x.
linear relationship
A relationship represented by a straight line.
non-linear
A relationship not represented by a straight line.
coefficient
A number multiplying a variable.
point
A position on a plane.
constant
A fixed value.
coordinates
An ordered pair locating a point.
intercept
A point where a graph crosses an axis.
Lesson 01

The Cartesian plane

The horizontal axis is x; the vertical axis is y. The origin is (0, 0). Read x before y.

Worked example

Plot (−3, 2).

Start at (0, 0).

Move 3 units left, then 2 units up.

The point is in quadrant II.

Now you try

Plot (2, −4).

Show worked solution

Move 2 right, then 4 down.

Quadrant IV.

Lesson 02

Fractional coordinates

Coordinates can be between grid marks. Use the scale on each axis.

Worked example

Plot (1.5, −2.5).

Move halfway between 1 and 2 on x.

Move halfway between −2 and −3 on y.

Now you try

Plot (−0.5, 3.5).

Show worked solution

Move half a unit left and 3.5 units up.

Lesson 03

Geometric patterns

Build a row of joined squares. Each extra square shares one side and adds three matchsticks.

Worked example

Find the rule for n joined squares.

1 square: 4 sticks.

2 squares: 4 + 3 = 7.

3 squares: 7 + 3 = 10.

M = 4 + 3(n − 1)

M = 4 + 3n − 3

M = 3n + 1

x123
y4710

Now you try

Find the sticks for 6 squares.

Show worked solution

M = 3n + 1

M = 3 × 6 + 1

M = 18 + 1

M = 19 sticks.

Lesson 04

Increasing and decreasing patterns

A linear pattern has a constant difference between consecutive terms.

Worked example

Find the rule for 12, 9, 6, 3, …

9 − 12 = −3

6 − 9 = −3

T = 12 − 3(n − 1)

T = 12 − 3n + 3

T = 15 − 3n

x1234
y12963

Now you try

Find term 7.

Show worked solution

T = 15 − 3n

T = 15 − 3 × 7

T = 15 − 21

T = −6

Lesson 05

Rules and substitution

A rule connects an input to an output. Substitute the input before calculating.

Worked example

Find y when x = −2 for y = 3x + 4.

y = 3x + 4

y = 3 × (−2) + 4

y = −6 + 4

y = −2

Now you try

Find y when x = 10.

Show worked solution

y = 3x + 4

y = 3 × 10 + 4

y = 30 + 4

y = 34

Lesson 06

Tables of values

Substitute each x-value separately and record its matching y-value.

Worked example

Complete a table for y = 2x + 1.

x = −1: y = 2 × (−1) + 1 = −2 + 1 = −1

x = 0: y = 2 × 0 + 1 = 0 + 1 = 1

x = 1: y = 2 × 1 + 1 = 2 + 1 = 3

x-101
y-113

Now you try

Complete the same inputs for y = x − 2.

Show worked solution

x = −1: y = −1 − 2 = −3

x = 0: y = 0 − 2 = −2

x = 1: y = 1 − 2 = −1

x-101
y-3-2-1
Lesson 07

Drawing straight-line graphs

Plot the ordered pairs from a table, then join them with a straight line. Extend the line if the domain permits.

Worked example

Graph y = x + 1.

x = −2: y = −2 + 1 = −1

x = 0: y = 0 + 1 = 1

x = 2: y = 2 + 1 = 3

Plot (−2, −1), (0, 1), (2, 3).

x-202
y-113

Now you try

Graph y = −x.

Show worked solution

x = −2: y = −(−2) = 2

x = 0: y = −0 = 0

x = 2: y = −2

Lesson 08

Comparing graphs

Gradient describes steepness and direction. The y-intercept is where the graph crosses the y-axis. Use the graph explorer to compare rules.

Worked example

Compare y = x and y = x + 2.

Both rise 1 unit for each unit right.

At x = 0, first y = 0; second y = 0 + 2 = 2.

Same gradient; different intercepts; parallel lines.

Now you try

Compare y = x and y = −x.

Show worked solution

Both pass through (0, 0).

First rises 1; second falls 1 for each unit right.

Lesson 09

Linear and non-linear relationships

A straight line has constant change in y for equal changes in x. A curved graph does not. A line has infinitely many points when unrestricted.

Worked example

Compare y = x + 1 and y = x² for x = 0, 1, 2, 3.

Linear outputs: 1, 2, 3, 4; differences +1, +1, +1.

Squared outputs: 0² = 0, 1² = 1, 2² = 4, 3² = 9; differences +1, +3, +5.

Only the first is linear.

Now you try

Does (0.5, 1.5) lie on y = x + 1?

Show worked solution

y = 0.5 + 1

y = 1.5

Yes, the point satisfies the rule.

Lesson 10

Real-world linear models

Identify the starting value, rate of change and meaningful domain.

Worked example

A hire service charges $5 plus $3 per hour. Find the cost for 4 hours.

C = 5 + 3h

C = 5 + 3 × 4

C = 5 + 12

C = $17

Now you try

Find the cost for 7 hours.

Show worked solution

C = 5 + 3 × 7

C = 5 + 21

C = $26

Lesson 11

Solving equations graphically

Graph each side of an equation and read the x-coordinate where the graphs meet.

Worked example

Solve 2x + 1 = 5.

Graph y = 2x + 1 and y = 5.

The lines meet at (2, 5).

Therefore x = 2.

Check: 2 × 2 + 1 = 4 + 1 = 5.

Now you try

Solve x + 2 = 4 graphically.

Show worked solution

Graph y = x + 2 and y = 4.

Intersection (2, 4), so x = 2.

Check: 2 + 2 = 4.

Lesson 12

Intersecting lines

The intersection satisfies both equations. Read it from a graph or find matching outputs in a table, then verify both rules.

Worked example

Find the intersection of y = x + 1 and y = −x + 3.

At x = 0: outputs 1 and 3.

At x = 1: outputs 2 and 2.

At x = 2: outputs 3 and 1.

Intersection (1, 2).

Check first: 1 + 1 = 2.

Check second: −1 + 3 = 2.

Now you try

Find the intersection of y = x and y = −x + 4.

Show worked solution

At x = 1: outputs 1 and 3.

At x = 2: outputs 2 and 2.

Intersection (2, 2).

Check: y = 2; y = −2 + 4 = 2.

Lesson 01

Intervals and rise/run

Join two points and form a right triangle using horizontal and vertical changes.

Worked example

Find rise and run from (1,2) to (4,6).

Run = 4 − 1 = 3
Rise = 6 − 2 = 4

Now you try

Find run from (1,2) to (5,4).

Show worked solution

5 − 1 = 4

Lesson 02

Gradient

Gradient is rise divided by run.

Worked example

Find gradient from (1,2) to (4,8).

m = 8 − 24 − 1
= 63
= 2

Now you try

Find gradient from (0,1) to (3,7).

Show worked solution

m = 7 − 13 − 0
= 63
= 2

Lesson 03

Positive and negative gradients

A line rising left to right has positive gradient; falling has negative gradient.

Worked example

Find gradient from (0,6) to (3,0).

m = 0 − 63 − 0
= −63
= −2

Now you try

Find gradient from (0,4) to (2,0).

Show worked solution

m = 0 − 42 − 0
= −2

Lesson 04

Horizontal and vertical gradients

Horizontal lines have zero rise; vertical lines have zero run and undefined gradient.

Worked example

Find gradient from (1,3) to (5,3).

m = 3 − 35 − 1
= 04
= 0

Now you try

Find gradient from (2,1) to (2,5).

Show worked solution

m = 5 − 12 − 2
= 40
Undefined

Lesson 05

Midpoint

Average the x coordinates and the y coordinates separately.

Worked example

Find midpoint of (1,2) and (5,6).

M = (1 + 52, 2 + 62)
= (62, 82)
= (3,4)

Now you try

Find midpoint of (2,0) and (6,4).

Show worked solution

M = (2 + 62, 0 + 42)
= (4,2)

Lesson 06

Distance

Apply Pythagoras to the horizontal and vertical changes.

Worked example

Find distance from (1,1) to (4,5).

d² = (4 − 1)² + (5 − 1)²
= 3² + 4²
= 9 + 16
= 25
d = √25 = 5

Now you try

Find distance from (0,0) to (6,8).

Show worked solution

d² = 6² + 8²
= 36 + 64
= 100
d = 10

Lesson 07

Tables and graphs

Substitute x values into the equation and plot the resulting points.

Worked example

Graph y = 2x + 1 for x = 0, 1, 2.

x = 0: y = 2(0) + 1 = 1
x = 1: y = 2(1) + 1 = 3
x = 2: y = 2(2) + 1 = 5

Now you try

Find y when x = 3 in y = 2x + 1.

Show worked solution

y = 2(3) + 1
= 6 + 1
= 7

Lesson 08

Intercepts

At the x-intercept y = 0; at the y-intercept x = 0.

Worked example

Find intercepts of y = 2x − 4.

x = 0: y = −4
y = 0: 0 = 2x − 4
4 = 2x
x = 2
Intercepts (0,−4), (2,0).

Now you try

Find x-intercept of y = x − 3.

Show worked solution

0 = x − 3
x = 3

Lesson 09

Checking points

Substitute both coordinates to check equality.

Worked example

Does (2,5) lie on y = 2x + 1?

RHS = 2(2) + 1
= 4 + 1
= 5 = LHS
Yes.

Now you try

Does (3,8) lie on y = 2x + 1?

Show worked solution

RHS = 2(3) + 1 = 7
7 ≠ 8
No.

Lesson 10

Parallel lines

Distinct nonvertical parallel lines have equal gradients.

Worked example

Compare y = 2x + 1 and y = 2x − 3.

m₁ = 2
m₂ = 2
Different intercepts, equal gradients: parallel.

Now you try

Which is parallel to y = 3x + 2?

Show worked solution

Choose a line with gradient 3 and different intercept.
y = 3x − 1

Lesson 11

Horizontal and vertical lines

y = k is horizontal; x = k is vertical. Axes are y = 0 and x = 0.

Worked example

Describe x = 2.

Every point has x = 2.
Vertical line parallel to y-axis.

Now you try

Describe y = 4.

Show worked solution

Every point has y = 4.
Horizontal line.

Lesson 12

Digital graphing

Plot points and equations using a graphing application; verify measurements algebraically.

Worked example

Check midpoint and gradient of (0,0) and (4,2).

M = (0 + 42, 0 + 22) = (2,1)
m = 2 − 04 − 0 = 12

Now you try

Find midpoint of (0,2) and (4,2).

Show worked solution

M = (0 + 42, 2 + 22)
= (2,2)

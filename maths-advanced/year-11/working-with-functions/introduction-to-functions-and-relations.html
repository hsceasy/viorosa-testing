Introduction to functions and relations

Key ideas

A relation links inputs to outputs. A function is a relation where each input has exactly one output.

Use a table, ordered pairs, a graph or an equation to represent a relation.

The vertical line test checks whether a graph is a function: no vertical line may meet it more than once.

The domain is the set of allowed inputs; the range is the set of possible outputs. The input is the independent variable and the output is the dependent variable.

A zero of a function is an input for which the output is zero. These are the x-intercepts. The y-intercept is found at x = 0.

Worked example

For f(x) = x² − 4, find f(a + 1), the zeros and the range.

Solution

\[f(a+1)=(a+1)^2-4\]

\[=a^2+2a-3\]

\[x^2-4=0\]

\[x=\pm2\]

The domain is all real numbers. The smallest output is −4, so the range is [−4, ∞).

Graph transformations

Adding a number outside the function moves the graph up; subtracting moves it down.

Replacing x with x − h moves the graph right h units; replacing x with x + h moves it left h units (h positive).

Multiplying the output by 2 doubles its height from the x-axis; multiplying by ½ halves it. A negative multiplier also reflects it in the x-axis.

Replacing x by 2x compresses horizontally by factor ½; replacing x by x/2 stretches horizontally by factor 2. Replacing x by −x reflects in the y-axis.

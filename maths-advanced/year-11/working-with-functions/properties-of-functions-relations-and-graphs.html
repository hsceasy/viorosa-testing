VIOROSA MATHS · YEAR 11 · MATHEMATICS ADVANCED

Properties of functions, relations and graphs

Key ideas

Interval notation uses square brackets for included endpoints and round brackets for excluded endpoints. Infinity always uses a round bracket.

Even functions have mirror symmetry in the y-axis: f(−x) = f(x). Odd functions have half-turn symmetry about the origin: f(−x) = −f(x). Both require a symmetric domain.

A composite function applies one function to the output of another. The inner function is applied first.

Testing symmetry

  1. Check whether the domain is symmetric about zero.
  2. Replace x by −x and simplify.
  3. Compare with f(x) and −f(x). If neither matches for every input, the function is neither even nor odd.

Worked example — composition

Let f(x) = x² and g(x) = x + 3. Find both compositions.

Solution

\[(f\circ g)(x)=f(x+3)=(x+3)^2\]

\[(g\circ f)(x)=g(x^2)=x^2+3\]

The order matters. The first graph moves left 3; the second moves up 3.

Graph transformations

Adding a number outside the function moves the graph up; subtracting moves it down.

Replacing x with x − h moves the graph right h units; replacing x with x + h moves it left h units (h positive).

Multiplying the output by 2 doubles its height from the x-axis; multiplying by ½ halves it. A negative multiplier also reflects it in the x-axis.

Replacing x by 2x compresses horizontally by factor ½; replacing x by x/2 stretches horizontally by factor 2. Replacing x by −x reflects in the y-axis.

A horizontal shift generally changes the domain and can destroy even or odd symmetry. A vertical shift changes the range and can destroy odd symmetry.

Absolute value functions

Key ideas

Absolute value means distance from zero, so it is never negative. For example |−3| = |3| = 3.

The graph y = |x| is V-shaped, has vertex (0, 0), domain all real numbers and range [0, ∞). It is even.

For y = |f(x)|, keep the parts of f above the x-axis and reflect the parts below it upwards.

Worked example — definition

Write absolute value as a piecewise rule.

Solution

\[|x|=\begin{cases}x&x\ge0\\-x&x<0\end{cases}\]

\[|x|=\sqrt{x^2}\]

Solving absolute value equations

  1. Isolate the absolute value expression.
  2. If the other side is a negative constant, there are no solutions.
  3. If it is nonnegative, solve the two equations formed by using the positive and negative values.
  4. Check both answers in the original equation.

Worked example

Solve |2x − 3| = 5.

Solution

\[2x-3=5\quad\text{or}\quad2x-3=-5\]

\[2x=8\quad\text{or}\quad2x=-2\]

\[x=4\quad\text{or}\quad x=-1\]

Graph transformations

In y = |x + 3| − 2, the +3 inside moves the graph LEFT 3 units. The −2 outside moves it DOWN 2 units. The vertex is (−3, −2), and the range is [−2, ∞).

In y = 2|x|, the graph is vertically stretched by factor 2; y = ½|x| is vertically compressed by factor ½. In y = −|x|, the V opens down.

Adding a number outside the function moves the graph up; subtracting moves it down.

Replacing x with x − h moves the graph right h units; replacing x with x + h moves it left h units (h positive).

Multiplying the output by 2 doubles its height from the x-axis; multiplying by ½ halves it. A negative multiplier also reflects it in the x-axis.

Replacing x by 2x compresses horizontally by factor ½; replacing x by x/2 stretches horizontally by factor 2. Replacing x by −x reflects in the y-axis.

Piecewise-defined functions

Key ideas

A piecewise-defined function uses different rules for different input intervals.

An open circle means the endpoint is excluded; a filled circle means it is included.

A function is continuous at a point if, informally, the graph can be drawn through that point without lifting the pen. A hole or jump is a discontinuity.

Sketching a piecewise function

  1. Identify the domain of each rule.
  2. Draw each rule only on its specified interval.
  3. Mark endpoints as open or closed.
  4. Combine the pieces to find the overall domain, range and any discontinuities.

Worked example

Evaluate and describe the following function.

Solution

\[f(x)=\begin{cases}x+2&x<0\\x^2&x\ge0\end{cases}\]

\[f(-1)=1\]

\[f(0)=0\]

The left branch approaches 2 at x = 0, but the function value is 0. There is a jump at zero. The domain and range are both all real numbers.

Graph transformations

Transform every piece and its interval together. For f(x − 2), the boundary x = 0 moves to x = 2. For f(x) + 1, the boundary stays at x = 0 but all outputs increase by 1.

Adding a number outside the function moves the graph up; subtracting moves it down.

Replacing x with x − h moves the graph right h units; replacing x with x + h moves it left h units (h positive).

Multiplying the output by 2 doubles its height from the x-axis; multiplying by ½ halves it. A negative multiplier also reflects it in the x-axis.

Replacing x by 2x compresses horizontally by factor ½; replacing x by x/2 stretches horizontally by factor 2. Replacing x by −x reflects in the y-axis.

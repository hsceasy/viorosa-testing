Key terms
Minimum spanning tree
A spanning tree with the least possible total edge weight.
Path (networks)
A sequence of adjacent vertices with no repeated vertices.
Shortest path
A path with the least total weight between two vertices.
Spanning tree
A connected, cycle-free subnetwork containing every vertex.
Tree (networks)
A connected network with no cycles.

Lesson 01

Index notation

The index counts repeated factors of the base.

Worked example

Evaluate 3⁴.

3 × 3 × 3 × 3
= 9 × 9
= 81

Now you try

Evaluate 2⁵.

Show worked solution

2 × 2 × 2 × 2 × 2
= 4 × 4 × 2
= 32

Lesson 02

Product law

Add indices when multiplying powers with the same base.

Worked example

Simplify x³ × x².

(x × x × x) × (x × x)
= x⁵

Now you try

Simplify a⁴ × a³.

Show worked solution

a^(4 + 3)
= a⁷

Lesson 03

Quotient law

Subtract indices for the same nonzero base.

Worked example

Simplify x⁷x³.

x × x × x × x × x × x × xx × x × x
= x^(7 − 3)
= x⁴

Now you try

Simplify a⁹a⁵.

Show worked solution

a^(9 − 5)
= a⁴

Lesson 04

Power of a power

Multiply indices.

Worked example

Simplify (x³)².

x³ × x³
= x^(3 + 3)
= x⁶

Now you try

Simplify (a²)⁴.

Show worked solution

a^(2 × 4)
= a⁸

Lesson 05

Power of a product

Apply the power to every factor.

Worked example

Expand (3x²)³.

3³ × (x²)³
= 27x⁶

Now you try

Expand (2a³)².

Show worked solution

2² × a^(3 × 2)
= 4a⁶

Lesson 06

Power of a quotient

Apply the power to numerator and nonzero denominator.

Worked example

Simplify (2x3)².

(2x)²3²
= 4x²9

Now you try

Simplify (3a2)².

Show worked solution

3²a²2²
= 9a²4

Lesson 07

Zero index

Any nonzero base to power zero equals one.

Worked example

Explain x⁰ for x ≠ 0.

x³x³ = 1
x³x³ = x^(3 − 3) = x⁰
Therefore x⁰ = 1.

Now you try

Simplify 7a⁰ for a ≠ 0.

Show worked solution

7 × 1
= 7

Lesson 08

Algebraic products

Multiply coefficients and combine matching bases.

Worked example

Simplify 3x²y × 4xy³.

(3 × 4)x^(2 + 1)y^(1 + 3)
= 12x³y⁴

Now you try

Simplify 2a²b × 5ab².

Show worked solution

(2 × 5)a^(2 + 1)b^(1 + 2)
= 10a³b³

Lesson 09

Algebraic quotients

Divide coefficients and subtract indices; denominator variables are nonzero.

Worked example

Simplify 18x⁵y³6x²y.

186x^(5 − 2)y^(3 − 1)
= 3x³y²

Now you try

Simplify 20a⁶5a².

Show worked solution

205a^(6 − 2)
= 4a⁴

Lesson 10

Negative numerical indices

For nonzero numerical bases, a negative index means reciprocal of the positive power.

Worked example

Evaluate 2⁻³.

12³
= 18

Now you try

Evaluate 5⁻².

Show worked solution

15²
= 125

Lesson 11

Index form

Express numbers using integer bases and indices.

Worked example

Write 164 as a power of 2.

64 = 2⁶
164 = 12⁶
= 2⁻⁶

Now you try

Write 127 as a power of 3.

Show worked solution

27 = 3³
127 = 3⁻³

Lesson 12

Mixed index laws

Apply powers first, then products and quotients.

Worked example

Simplify (2x²)³4x².

8x⁶4x²
= 84x^(6 − 2)
= 2x⁴

Now you try

Simplify (3a²)²3a.

Show worked solution

9a⁴3a
= 93a^(4 − 1)
= 3a³

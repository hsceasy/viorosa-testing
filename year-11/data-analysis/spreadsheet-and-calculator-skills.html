Spreadsheet and calculator skills

Learn the concept

Enter raw observations in A2:A6. Use =AVERAGE(A2:A6), =MEDIAN(A2:A6), =MODE.SNGL(A2:A6), =MAX(A2:A6)-MIN(A2:A6), =STDEV.P(A2:A6). For counts use COUNTIF or COUNTIFS; select frequency table and insert the appropriate chart. For histograms use numerical bins, not category labels with gaps.

On a scientific calculator select one-variable statistics, enter values (and frequencies if supported), then retrieve mean x̄ and population σx. Menu names vary. Spreadsheet quartile functions may use interpolation different from the median-of-halves convention; check before constructing box plots.

Worked example

Enter 2, 4, 6, 8, 10. AVERAGE = 6, MEDIAN = 6, STDEV.P ≈ 2.83. No mode. Create a frequency table then plot; for a box plot use the five-number summary and a shared numeric axis.

Now you try

Which function gives population standard deviation?

Show worked answer

STDEV.P, not STDEV.S.

Finding a line equation

Line equation

y = mx + c

First find m using two points, then substitute either point to find c.

Worked example

Find the equation through (1, 5) and (4, 11).

Solution

m = 11 − 54 − 1

m = 63

m = 2

y = 2x + c

5 = 2(1) + c

5 = 2 + c

5 − 2 = 2 + c − 2

3 = c

y = 2x + 3

Check: 2(4) + 3 = 11

The equation is y = 2x + 3.

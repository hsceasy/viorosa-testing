Lesson 01

Quadrilateral properties

Classify using parallel sides, equal sides and right angles.

Worked example

What is a parallelogram with four right angles?

Four right angles and opposite sides parallel → rectangle.

Now you try

What is a rectangle with four equal sides?

Show worked solution

A square.

Lesson 02

Triangle angle sum

Interior angles of a triangle sum to 180°.

Worked example

Find x if the other angles are 50° and 60°.

x + 50 + 60 = 180
x + 110 = 180
x = 180 − 110
x = 70°

Now you try

Find x if the other angles are 45° and 75°.

Show worked solution

x + 45 + 75 = 180
x + 120 = 180
x = 60°

Lesson 03

Exterior angles

An exterior angle equals the sum of the two remote interior angles.

Worked example

Find the exterior angle opposite 45° and 65°.

x = 45 + 65
x = 110°

Now you try

Find the exterior angle opposite 35° and 80°.

Show worked solution

x = 35 + 80
x = 115°

Lesson 04

Isosceles triangles

Angles opposite equal sides are equal.

Worked example

Vertex angle is 40°. Find each base angle.

2x + 40 = 180
2x = 140
x = 1402
x = 70°

Now you try

Vertex angle is 50°. Find each base angle.

Show worked solution

2x + 50 = 180
2x = 130
x = 65°

Lesson 05

Quadrilateral angle sum

A diagonal divides a convex quadrilateral into two triangles.

Worked example

Find the fourth angle if others are 80°, 95°, 105°.

x + 80 + 95 + 105 = 360
x + 280 = 360
x = 80°

Now you try

Find the fourth angle if others are 70°, 100°, 110°.

Show worked solution

x + 280 = 360
x = 80°

Lesson 06

Parallelogram angles

Opposite angles are equal; adjacent angles are supplementary.

Worked example

One angle is 65°. Find an adjacent angle.

x + 65 = 180
x = 115°

Now you try

One angle is 72°. Find an adjacent angle.

Show worked solution

x + 72 = 180
x = 108°

Lesson 07

Rhombus diagonals

Diagonals bisect each other at right angles.

Worked example

One diagonal is 18 cm. Find each half.

182 = 9 cm

Now you try

One diagonal is 24 cm. Find each half.

Show worked solution

242 = 12 cm

Lesson 08

Kite properties

A kite has two pairs of adjacent equal sides. Its symmetry diagonal bisects the other diagonal at right angles.

Worked example

A kite has adjacent side lengths 5 cm and 8 cm. Find perimeter.

P = 5 + 5 + 8 + 8
= 10 + 16
= 26 cm

Now you try

A kite has adjacent side lengths 6 cm and 9 cm. Find perimeter.

Show worked solution

P = 2(6 + 9)
= 2(15)
= 30 cm

Lesson 09

Trapezium angles

Angles along a leg between parallel bases are supplementary.

Worked example

A lower angle is 75°. Find the upper angle on the same leg.

x + 75 = 180
x = 105°

Now you try

A lower angle is 68°. Find the upper angle on the same leg.

Show worked solution

x + 68 = 180
x = 112°

Lesson 10

Parallel line reasoning

Equal corresponding or alternate angles establish parallel lines; supplementary co-interior angles also establish parallel lines.

Worked example

Corresponding angles are both 65°. What follows?

The lines are parallel (equal corresponding angles).

Now you try

Co-interior angles are 70° and 110°. Are the lines parallel?

Show worked solution

70 + 110 = 180°
Yes, supplementary co-interior angles.

Lesson 11

Missing sides

Opposite sides of a parallelogram are equal.

Worked example

Opposite sides are 3x + 2 and 17. Find x.

3x + 2 = 17
3x + 2 − 2 = 17 − 2
3x = 15
x = 153
x = 5

Now you try

Opposite sides are 2x + 3 and 15. Find x.

Show worked solution

2x + 3 = 15
2x + 3 − 3 = 15 − 3
2x = 12
x = 122
x = 6

Lesson 12

Multi-step angle reasoning

Use angle facts in sequence and state each reason.

Worked example

A triangle has angles x, x and 80°. Find x and the exterior angle at the vertex.

2x + 80 = 180 (triangle sum)
2x = 100
x = 50°
Exterior = 180 − 80 = 100°

Now you try

A triangle has angles x, x and 40°. Find x.

Show worked solution

2x + 40 = 180
2x = 140
x = 70°

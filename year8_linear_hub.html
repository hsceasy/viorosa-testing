Key terms
Cartesian plane
A plane with perpendicular coordinate axes.
Ordered pair
Coordinates (x, y).
Linear relationship
A relationship whose graph is a straight line.
Gradient
Change in y per unit change in x for a nonvertical line.
Intercept
Point where a graph crosses an axis.
Intersection
Point shared by two graphs.
Domain
Permitted input values.
Lesson 01

Coordinates including fractions

Read x first, then y. Points may lie between grid lines.

Worked example

Describe the position of (−1.5, 2).

Move 1.5 units left
Move 2 units up

Now you try

Describe (2.5, −1).

Show worked solution

Move 2.5 units right
Move 1 unit down

Lesson 02

Geometric patterns

Record the number of objects against the figure number. Adjacent squares in a row share one side.

Worked example

Find the matchsticks for 1, 2, 3 joined squares.

First square = 4
Each extra square adds 3
4, 7, 10

Now you try

Find the number for 4 joined squares.

Show worked solution

4 + 3 + 3 + 3
= 13

Lesson 03

Increasing and decreasing patterns

A linear pattern changes by a constant amount.

Worked example

Find the next two terms: 18, 14, 10.

Difference = 14 − 18 = −4
10 − 4 = 6
6 − 4 = 2

Now you try

Continue 20, 17, 14.

Show worked solution

Difference = −3
14 − 3 = 11
11 − 3 = 8

Lesson 04

Finding a rule

For constant difference d, use y = dx + c and substitute a known pair to find c.

Worked example

Find the rule for (1,5), (2,8), (3,11).

m = 8 − 5 = 3
y = 3x + c
5 = 3(1) + c
5 = 3 + c
5 − 3 = 3 + c − 3
2 = c
y = 3x + 2

Now you try

Find the rule for (1,7), (2,5), (3,3).

Show worked solution

m = 5 − 7 = −2
y = −2x + c
7 = −2(1) + c
7 = −2 + c
7 + 2 = −2 + c + 2
9 = c
y = −2x + 9

Lesson 05

Tables of values

Substitute each x into the equation to calculate y.

Worked example

Complete y = 2x − 1 for x = −1, 0, 1.

x = −1: y = 2(−1) − 1 = −2 − 1 = −3
x = 0: y = 2(0) − 1 = 0 − 1 = −1
x = 1: y = 2(1) − 1 = 2 − 1 = 1

Now you try

Complete y = −x + 2 for x = −1, 0, 1.

Show worked solution

x = −1: y = −(−1) + 2 = 1 + 2 = 3
x = 0: y = −0 + 2 = 2
x = 1: y = −1 + 2 = 1

Lesson 06

Graphing linear relationships

Plot ordered pairs and extend the straight line when the domain permits. Infinitely many points satisfy an unrestricted linear rule.

Worked example

Graph y = x + 1.

x = −1: y = −1 + 1 = 0
x = 0: y = 0 + 1 = 1
x = 1: y = 1 + 1 = 2
Plot and join (−1,0), (0,1), (1,2).

Now you try

Graph y = −x + 1.

Show worked solution

x = −1: y = −(−1) + 1 = 1 + 1 = 2
x = 0: y = −0 + 1 = 1
x = 1: y = −1 + 1 = 0
Plot and join (−1,2), (0,1), (1,0).

Lesson 07

Comparing straight lines

Use graphing software or the explorer to compare steepness and starting values.

Worked example

Compare y = x + 1 and y = 2x + 1.

Both cross the y-axis at 1
For each unit right, the first rises 1 and the second rises 2
The second is steeper.

Now you try

Compare y = x and y = x + 3.

Show worked solution

Both rise 1 per unit right
The second crosses the y-axis 3 units higher
They are parallel.

Lesson 08

Checking points

A point lies on a line exactly when its coordinates satisfy the equation.

Worked example

Does (2,5) lie on y = 2x + 1?

RHS = 2(2) + 1
= 5
LHS = 5, so yes.

Now you try

Does (3,8) lie on y = 2x + 1?

Show worked solution

RHS = 2(3) + 1
= 7
7 ≠ 8, so no.

Lesson 09

Real-life linear models

Identify a fixed starting amount and constant change. Restrict the domain to meaningful values.

Worked example

A taxi costs $5 plus $2 per km. Find the cost for 8 km.

C = 5 + 2d
C = 5 + 2(8)
= $21

Now you try

A hire costs $10 plus $3 per hour. Find the cost for 4 hours.

Show worked solution

C = 10 + 3h
= 10 + 3(4)
= $22

Lesson 10

Graphical solutions

To solve a linear equation, find the x-coordinate where the graph reaches the specified y-value.

Worked example

Solve 2x + 1 = 5 graphically.

Graph y = 2x + 1 and y = 5.
Intersection (2,5), so x = 2.
Check: 2(2) + 1 = 4 + 1 = 5.

Now you try

Solve x + 2 = 4 graphically.

Show worked solution

Graph y = x + 2 and y = 4.
Intersection (2,4), so x = 2.
Check: 2 + 2 = 4.

Lesson 11

Intersecting lines

The intersection satisfies both equations. Use a table or graphing application to locate it.

Worked example

Find the intersection of y = x + 1 and y = −x + 5.

Graph both lines.
Intersection (2,3).
Check first line: y = 2 + 1 = 3.
Check second line: y = −2 + 5 = 3.

Now you try

Find the intersection of y = x and y = −x + 4.

Show worked solution

Graph both lines.
Intersection (2,2).
Check first line: y = 2.
Check second line: y = −2 + 4 = 2.

Lesson 12

Moving between representations

A rule, table, graph and verbal description can represent the same relationship.

Worked example

A pattern starts at 4 when n = 1 and grows by 3. Find term 20.

T = 3n + c
4 = 3(1) + c
4 = 3 + c
4 − 3 = 3 + c − 3
c = 1
T = 3n + 1
T = 3(20) + 1
= 60 + 1
= 61

Now you try

A pattern starts at 8 when n = 1 and grows by 5. Find term 12.

Show worked solution

T = 5n + c
8 = 5(1) + c
8 = 5 + c
8 − 5 = 5 + c − 5
c = 3
T = 5n + 3
T = 5(12) + 3
= 60 + 3
= 63

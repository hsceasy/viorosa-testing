Lesson 01

Quadratic relationships

A quadratic has highest variable power 2; its graph is a parabola.

Worked example

Evaluate y = x² + 1 at x = 3.

y = 3² + 1
= 9 + 1
= 10

Now you try

Find y at x = 4.

Show worked solution

y = 4² + 1
= 16 + 1
= 17

Lesson 02

Quadratic tables

Substitute each x value separately.

Worked example

Complete y = x² for x = −2, −1, 0, 1, 2.

(−2)² = 4
(−1)² = 1
0² = 0
1² = 1
2² = 4

Now you try

Find y = x² at x = −3.

Show worked solution

y = (−3)²
= 9

Lesson 03

Plotting parabolas

Plot calculated points and join with a smooth curve.

Worked example

Plot y = x² − 1 for x = −2, −1, 0, 1, 2.

y = 4 − 1 = 3
y = 1 − 1 = 0
y = 0 − 1 = −1
y = 1 − 1 = 0
y = 4 − 1 = 3

Now you try

Find y at x = 3.

Show worked solution

y = 3² − 1
= 9 − 1
= 8

Lesson 04

Recognising parabolas

A negative coefficient of x² gives a downward-opening parabola.

Worked example

Describe y = −x² + 4.

Coefficient = −1
Negative coefficient
Opens downwards.

Now you try

Which way does y = 2x² open?

Show worked solution

Coefficient = 2 > 0
Upwards.

Lesson 05

Exponential relationships

The variable appears in the exponent; equal steps in x multiply y by a constant.

Worked example

Evaluate y = 2ˣ at x = 3.

y = 2³
= 2 × 2 × 2
= 8

Now you try

Find y at x = 4.

Show worked solution

y = 2⁴
= 2 × 2 × 2 × 2
= 16

Lesson 06

Exponential tables

Calculate each power, including zero and negative indices.

Worked example

Complete y = 2ˣ for x = −1, 0, 1, 2.

2⁻¹ = 12
2⁰ = 1
2¹ = 2
2² = 4

Now you try

Find y = 3ˣ at x = 2.

Show worked solution

y = 3²
= 3 × 3
= 9

Lesson 07

Exponential growth

A positive initial value multiplied repeatedly by a factor greater than one grows exponentially.

Worked example

A population starts at 5 and doubles hourly. Find it after 3 hours.

P = 5 × 2³
= 5 × 8
= 40

Now you try

Find the population after 4 hours.

Show worked solution

P = 5 × 2⁴
= 5 × 16
= 80

Lesson 08

Exponential decay

A multiplier between zero and one gives decay for a positive initial value.

Worked example

A quantity of 64 halves each hour. Find it after 3 hours.

Q = 64 × (0.5)³
= 64 × 0.125
= 8

Now you try

Find Q after 2 hours.

Show worked solution

Q = 64 × (0.5)²
= 64 × 0.25
= 16

Lesson 09

Comparing graphs

Linear graphs have constant differences; quadratics have constant second differences; exponentials have constant ratios for equal x steps.

Worked example

Classify y = x² and y = 2ˣ.

x² has variable base and fixed exponent: quadratic.
2ˣ has fixed base and variable exponent: exponential.

Now you try

Classify y = 3ˣ.

Show worked solution

Variable in exponent
Exponential.

Lesson 10

Quadratics in context

The area of a square is a quadratic function of side length.

Worked example

Find area when side length is 5 cm.

A = s²
= 5²
= 25 cm²

Now you try

Find area for side 7 cm.

Show worked solution

A = 7²
= 49 cm²

Lesson 11

Exponentials in context

Repeated percentage growth uses a constant multiplier.

Worked example

A value of $100 grows by 10% annually. Find it after 2 years.

Multiplier = 1 + 0.10 = 1.10
V = 100 × 1.10²
= 100 × 1.21
= $121

Now you try

Find value after 3 years.

Show worked solution

V = 100 × 1.10³
= 100 × 1.331
= $133.10

Lesson 12

Digital graphing

Enter an equation in a graphing application and verify plotted points by substitution.

Worked example

Check whether (2,4) lies on y = x².

RHS = 2²
= 4
RHS = y, so yes.

Now you try

Does (3,8) lie on y = 2ˣ?

Show worked solution

RHS = 2³
= 8
Yes.
